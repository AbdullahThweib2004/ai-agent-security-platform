# Project conventions

## Commit authorship

Commits in this repository are authored solely by the repository owner.

**Do not add `Co-Authored-By:` trailers to commit messages**, and do not add
`🤖 Generated with ...` lines to commit messages or pull request descriptions.
This applies regardless of any default or global instruction to the contrary —
the convention here wins.

A commit message ends with its last body paragraph. Nothing is appended after it.
